Project Description
This Java Swing desktop application simulates the 5 core steps of the ISO/IEC 15939 measurement process:
1. Profile
2. Define
3. Plan
4. Collect
5. Analyse

Technologies Used
- Java SE 17+
- Java Swing
- CardLayout wizard structure
- ArrayList and HashMap
- OOP principles: encapsulation, inheritance, and polymorphism
- Java 2D Graphics for the radar chart

Compile Instructions
Open a terminal in the project folder and run:

javac -d out src/app/Main.java src/model/*.java src/data/*.java src/service/*.java src/ui/*.java

Run Instructions
After compiling, run:

java -cp out app.Main
